# 《面向对象与数据库课程设计》课程设计说明书

## 1 引言  
### 1.1 项目背景  
随着城市现代化进程的加速，城市公共设施的数量和种类不断增加，传统的人工报修与管理方式已无法满足高效、便捷的需求。目前城市公共设施管理存在报修响应慢、维修流程不透明、状态监控不及时等问题，导致市民满意度下降，管理成本增加。因此，开发一套智能的城市公共设施报修与状态监控平台显得尤为重要。

### 1.2 项目目的  
本项目旨在设计并实现一个基于面向对象和数据库技术的城市公共设施智能报修与状态监控平台，实现以下目标：
- 提供便捷的市民报修渠道
- 实现报修流程的规范化管理
- 实时监控公共设施的运行状态
- 提高维修效率和市民满意度
- 降低管理成本，提升城市管理水平

### 1.3 项目意义  
该项目的实施将为城市公共设施管理带来以下积极意义：
- 技术意义：综合运用面向对象设计、数据库设计、Web开发等技术，提升学生的实践能力
- 社会意义：提高城市公共设施管理效率，方便市民生活，提升城市形象
- 经济意义：降低管理成本，提高资源利用效率，创造更大的社会效益

## 2 系统需求分析  
### 2.1 功能需求分析  
城市公共设施智能报修与状态监控平台主要包含以下功能模块：

#### 2.1.1 用户管理模块  
- **用户注册与登录**：支持市民、维修人员和管理员的注册与登录
- **用户信息管理**：维护用户基本信息，包括个人资料、联系方式等
- **权限管理**：根据用户角色（市民、维修人员、管理员）分配不同的操作权限

#### 2.1.2 设施管理模块  
- **设施信息管理**：录入和维护公共设施的基本信息，包括设施类型、位置、型号等
- **设施状态监控**：实时监控设施的运行状态，如路灯、垃圾桶、健身器材等
- **设施分类管理**：对设施进行分类管理，便于查询和统计

#### 2.1.3 报修管理模块  
- **报修申请**：市民可以通过平台提交设施报修申请，上传照片和描述问题
- **报修审核**：管理员对报修申请进行审核，确认报修内容和优先级
- **报修查询**：市民可以查询自己的报修进度和处理结果

#### 2.1.4 维修管理模块  
- **维修任务分配**：管理员将审核通过的报修任务分配给维修人员
- **维修进度跟踪**：维修人员实时更新维修进度，包括开始维修、维修中、已完成等状态
- **维修结果反馈**：维修完成后，维修人员上传维修结果和相关照片

#### 2.1.5 统计分析模块  
- **报修统计**：统计不同时间段、不同区域、不同类型设施的报修数量
- **维修效率分析**：分析维修人员的工作效率，包括平均维修时间、完成率等
- **设施状态分析**：分析设施的故障率、使用寿命等，为设施维护提供参考

#### 2.1.6 通知管理模块  
- **系统通知**：向用户发送系统公告、维修进度更新等通知
- **消息推送**：通过短信、邮件等方式向用户推送重要信息

#### 2.1.7 评价管理模块  
- **维修评价**：市民可以对维修服务进行评价和反馈
- **评价统计**：统计维修人员的评价得分，作为绩效考核的依据

#### 2.1.8 系统管理模块  
- **数据备份与恢复**：定期备份系统数据，确保数据安全
- **日志管理**：记录系统的操作日志，便于审计和问题追踪
- **参数设置**：设置系统的基本参数，如报修优先级、通知方式等

### 2.2 非功能需求分析  
- **性能需求**：系统响应时间不超过3秒，支持同时在线用户数不少于1000人
- **可靠性需求**：系统可用性达到99.9%，数据丢失率为0
- **安全性需求**：确保用户数据安全，防止未授权访问和数据泄露
- **可扩展性需求**：系统架构应具有良好的可扩展性，便于后续功能扩展
- **易用性需求**：界面友好，操作简单，无需专业培训即可使用

## 3 系统设计  
### 3.1 系统总体结构设计  
本系统采用三层架构设计：

1. **表示层**：负责用户界面的展示和用户交互，采用Web前端技术实现
2. **业务逻辑层**：处理系统的核心业务逻辑，实现各功能模块的业务规则
3. **数据访问层**：负责与数据库的交互，实现数据的增删改查操作

3. **报修模块**：实现报修申请的提交、审核和查询
4. **维修模块**：实现维修任务的分配、进度跟踪和结果反馈

#### 4.2.1 用户管理功能实现  

**1. 用户实体类（User.java）**
```java
package com.city.facility.entity;

import lombok.AllArgsConstructor;
import lombok.Builder;
import lombok.Data;
import lombok.NoArgsConstructor;

import javax.persistence.*;
import java.time.LocalDateTime;

@Data
@NoArgsConstructor
@AllArgsConstructor
@Builder
@Entity
@Table(name = "user", indexes = {
    @Index(name = "idx_phone", columnList = "phone"),
    @Index(name = "idx_user_type", columnList = "user_type")
})
public class User {
    
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(unique = true, nullable = false, length = 20)
    private String phone;
    
    @Column(nullable = false, length = 100)
    private String password;
    
    @Column(name = "real_name", length = 50)
    private String realName;
    
    @Column(name = "user_type", nullable = false)
    @Convert(converter = com.city.facility.converter.UserTypeConverter.class)
    private UserType userType;
    
    @Column(name = "status", nullable = false)
    @Convert(converter = com.city.facility.converter.UserStatusConverter.class)
    private UserStatus status;
    
    @Column(nullable = false, updatable = false)
    private LocalDateTime createTime;
    
    @Column(nullable = false)
    private LocalDateTime updateTime;
    
    @PrePersist
    protected void onCreate() {
        createTime = LocalDateTime.now();
        updateTime = LocalDateTime.now();
        if (status == null) {
            status = UserStatus.ACTIVE;
        }
        if (userType == null) {
            userType = UserType.CITIZEN;
        }
    }
    
    @PreUpdate
    protected void onUpdate() {
        updateTime = LocalDateTime.now();
    }
    
    public enum UserType {
        CITIZEN,    // 普通市民
        WORKER,     // 维修工
        ADMIN       // 管理员
    }
    
    public enum UserStatus {
        ACTIVE,     // 激活
        INACTIVE,   // 停用
        BANNED      // 封禁
    }
}
```

**4. 用户服务实现（UserService.java - 登录部分）**
```java
public User login(String phone, String password) {
    User user = userRepository.findByPhone(phone)
            .orElseThrow(() -> new RuntimeException("用户不存在"));
    
    // 直接比较密码（根据需求移除了加密）
    if (!user.getPassword().equals(password)) {
        throw new RuntimeException("密码错误");
    }
    
    if (user.getStatus() != User.UserStatus.ACTIVE) {
        throw new RuntimeException("用户已被禁用");
    }
    
    return user;
}
```

# 城市公共设施智能报修与状态监控平台 - 数据库设计文档

## 1. 系统概述
本系统是一个面向市政管理部门和市民的公共设施报修与监控平台，支持设施资产管理、报修单管理、维修工管理以及统计分析功能。

## 3. 数据字典

### 用户类型(user_type)
- `citizen`: 普通市民
- `worker`: 维修工
- `admin`: 系统管理员

### 用户状态(status)
- `active`: 激活
- `inactive`: 停用
- `banned`: 封禁

### 设施类型(facility_type)
- `street_light`: 路灯
- `park_bench`: 公园长椅
- `public_toilet`: 公共厕所
- `fitness_equipment`: 健身器材

### 设施状态(status)
- `normal`: 正常
- `broken`: 损坏
- `repairing`: 维修中
- `discarded`: 已报废

### 报修单状态(status)
- `submitted`: 已提交
- `accepted`: 已接受
- `processing`: 维修中
- `completed`: 已完成

### 维修工状态(status)
- `available`: 可用(无任务)
- `busy`: 忙碌(有任务)
- `offline`: 离线

### 预警级别(alarm_level)
- `low`: 低
- `medium`: 中
- `high`: 高

## 4. 关键业务规则

### 4.1 报修单自动分配规则
1. 当市民提交报修单时，系统自动查询所有可用维修工
2. 选择待办任务最少(pending_count最小)的维修工进行分配
3. 更新维修工的pending_count字段
4. 向维修工发送通知消息

### 4.2 超时预警规则
1. 定时任务每小时检查一次所有维修中的报修单
2. 如果设施状态为"维修中"超过48小时，生成超时预警
3. 预警通知发送给对应的管理员

### 4.3 故障率计算
- 故障率 = 故障数 / 总数 * 100%
- 统计维度：按设施类型分类统计

### 4.4 平均维修耗时计算
- 平均维修耗时 = Σ(完成时间 - 提交时间) / 完成的报修单数量
